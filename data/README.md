# 7단계 미세 조정 데이터

| 파일 | 쌍 | 문서 | 질의/문서 | 다루는 항목 |
| --- | --- | --- | --- | --- |
| `train.jsonl` | 282 | 94 | 3 | CO2·환기 12, 냉난방 12, 공기질 12, 센서·네트워크 12, 경보 12, 에이전트 12, 엣지 운영 11, 과정 운영 11 |
| `eval.jsonl` | 60 | 20 | 3 | 온도·습도·PM2.5·조도·소음·TVOC·재실 인원·냉난방·환기·센서 관리·경보·에이전트 권한 |

형식은 강의자료 7단계와 같아요. 한 줄에 `{"anchor": 질의, "positive": 정답 문서}` 가 들어 있어요.

## 어떻게 만들었나

- 강의자료는 두 파일이 "제공된다"고 적었지만, 실습 시점에 받은 파일이 없었어요. 그래서 자료에 적힌 규모와 항목을 그대로 따라 **AI(Claude)로 새로 작성**했어요.
  - 규모: 학습 282쌍(문서 94개), 평가 60쌍(문서 20개), 문서마다 질의 3개
  - 항목 목록도 자료와 같아요.
- 문서의 수치(온도 22~26도, CO2 1000ppm 등)는 **실습용 가상 운영 기준**이에요. 실제 학교 규정이 아니에요.
- 질의는 교육생이 실제로 할 법한 구어체로 썼어요. 문서와 같은 단어를 일부러 피해서, 단순한 단어 일치로는 정답을 맞히기 어렵게 했어요.
  - 예: "겨울에 눈이 뻑뻑하고 정전기가 나요" → 습도 기준 문서
- 같은 배치 안의 다른 문서가 오답으로 쓰이므로(MultipleNegativesRankingLoss), 내용이 거의 같은 문서는 만들지 않았어요.

## 검증

평가 문서·질의가 학습 데이터와 하나도 겹치지 않는지, 문서마다 질의가 3개인지 아래 명령으로 확인했어요. 결과는 `282 60 94 20 0 0` 이었어요.

```bash
python3 -c "
import json, collections
t=[json.loads(l) for l in open('data/train.jsonl')]; e=[json.loads(l) for l in open('data/eval.jsonl')]
td={r['positive'] for r in t}; ed={r['positive'] for r in e}
assert set(collections.Counter(r['positive'] for r in t+e).values())=={3}
print(len(t), len(e), len(td), len(ed), len(td&ed), len({r['anchor'] for r in t}&{r['anchor'] for r in e}))
"
```

남은 한계: 평가와 학습은 같은 사람(AI)이 같은 말투로 썼어요. 그래서 학습 후 점수가 오른 폭에는 "말투에 익숙해진 효과"가 섞여 있을 수 있어요. 그래서 3단계 일반 질의도 다시 돌려 일반 성능이 떨어지지 않았는지 함께 확인해요.
