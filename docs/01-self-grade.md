# 1~10단계 결과 점검과 셀프 채점

점검일: 2026-10-26, 최종 갱신 2026-10-28 · 기준: 원본 강의자료 "Jetson 실습 - EmbeddingGemma 2 멀티모달 임베딩"(2026-10-08)의 단계별 결과표·확인 포인트·확장 과제, 팀 AI 채점 가이드의 추정 루브릭 A(과제). 1~5절은 1~9단계, 10단계(10-27~28 진행)는 [6절](#6-10단계-점검-2026-10-28-추가)에 따로 적었습니다.

## 요약

- **문제**: 강의자료에는 채점 기준이 없고, 대신 단계마다 직접 채우는 결과표가 있습니다. 이 표가 모두 채워졌는지, 그리고 추정 루브릭 A로 몇 점인지 확인했습니다.
- **결과**: 1~7단계는 핵심 결과표(3단계 정답, 6단계 자원표 3행, 7단계 학습 전/후)가 채워졌고, 빈칸은 동영상(4·6단계), 전체 모델 행, 변형·확장 과제입니다. 8·9단계는 측정은 했지만 **강의자료 표 형식(8-4 물체별 라벨표, 9-4 횟수표, 9-5, 9-6)이 대부분 비어 있습니다.** 요구 항목 37개 중 충족 19, 부분 6, 미실시 12였고, 10-26 재측정(오전 동영상·전체 모델, 오후 8-4 물체 비교) 뒤 충족 29, 부분 3, 미실시 5, 10-26 늦은 오후 사람 목소리·9-3~9-6 측정 뒤 충족 34, 부분 2, 미실시 1, 10-27 팀원 A 와 악수·처음 보는 사람 평가 뒤 **충족 36, 부분 1, 미실시 0** 입니다.
- **셀프 채점**: 79점 → 문서 보강 뒤 85점 → 10-26 오전 재측정 뒤 87점 → 오후 8-4 물체 비교 뒤 90점 → 평가 데이터 사람 검수 뒤 92점 → 사람 목소리·9단계 실측 뒤 99점 → 10-27 악수·처음 보는 사람 평가 뒤 **100점**. 남은 부분 충족 1칸(8단계 yoloe+relabel 확장)은 선택 확장 과제라 감점 요인으로 보지 않았습니다. 10단계까지 넣어 다시 매기면 **98점**(결과와 근거 15 → 13)입니다. 10단계는 10칸 중 충족 2 · 부분 3 · 미실시 5 이고, stereo·fused·접근 알람을 재지 못한 이유를 문제 해결 기록 31 로 남겼습니다(6절). 이 점수는 추정 루브릭 기준이라 강사님 채점과 같다는 보장은 없습니다.

## 4. 이번 보강에서 한 것 (문서·코드)

- `lab/test_vision.py`: `--video-frames`(torchcodec 없이 OpenCV 로 1 fps 프레임을 뽑아 동영상 벡터를 만듦), `--mixed`(텍스트+이미지 혼합 입력).
- `lab/test_all.py`: 전체 모델(740M)에 이미지·음성·동영상 프레임을 한 인덱스로 넣고 6개 질의로 찾음 → `results/06_all.jsonl`, `results_table.py` 표에 자동 포함.
- `lab/app.py`: `--min-score`(확장 과제 점수 필터), `--probe`(끝낼 때 검색 결과 상위 3개 기록).
- 결과 파일에 카메라 IP 대신 `rtsp://<카메라>/stream2` 만 남기도록 `camera.source_label()` 추가, 기존 결과 7줄도 같은 형식으로 바꿈. README 의 Tailscale 주소도 가림(이전 커밋 기록에는 남아 있음).
- README: 8-4·9-4 를 강의자료 표 형식으로 정리(빈칸은 "미측정"), 8단계 방식 선택 결론, 기술적 고민 표에 "결과" 열, 회고, 이 문서 링크.

검증: 클라우드 환경에서 `python -m py_compile lab/*.py`, `results_table.py` 가 기존 결과로 같은 표를 출력하는지, `source_label()` 이 `@` 가 든 계정·USB 번호에서 IP·계정을 남기지 않는지 확인했습니다. 새 옵션의 실제 동작은 위 재측정에서 처음 확인됩니다.
