## 결과

- **Y 20개 / N 0개** (민서, 2026-10-26).
- 3번은 처음에 "2번 질문과 같음"이라고 적었습니다. 질문이 중복이라는 뜻인지 다시 확인했고, "정답 문서만 같고 짝은 맞다(Y)"로 정리했습니다. 한 문서에 질문 2~3개가 붙는 것은 평가 데이터를 만들 때 의도한 구성입니다(6·7번 조도, 9~11번 소음, 12~14번 정원도 같음).
- N 이 없어 `data/eval.jsonl` 은 고치지 않았고, 7단계 점수(accuracy@1 0.833 → 0.850)도 그대로입니다.
- **한계**: 60쌍 중 20쌍(33%)만 봤고 검수자는 1명입니다. 나머지 40쌍과 학습 데이터 282쌍은 사람이 보지 않았습니다.
